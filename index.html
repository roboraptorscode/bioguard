    Which Vision AI model should BIOGUARD use?

    Smart Logic (built in) works with no training. It finds plants by how green each pixel is (the Excess Green index, ExG = 2G − R − B). If it sees two or more clear crop rows, plants in the rows are crop and plants between rows are weeds. If there are no rows, it compares leaf colour instead: the most common plant colour is treated as the crop and a clearly different colour as weed. If every plant looks alike, it calls them all crop rather than guessing. It is quick but rough, because many weeds are the same green as the crop.

    Claude Vision actually recognizes plants. It looks at one frame, names the crop, and labels every zone. It runs only in the published Claude page, so use it with uploaded field photos or videos. It is slower (a few seconds per frame) and uses your Claude plan.

    For live camera scanning, train your own model. A Teachable Machine model learns what your crop and your weeds look like, then runs on every frame in real time, even in the downloaded file.

    Next level: a small object-detection model such as Ultralytics YOLO (nano size) trained on public weed datasets like DeepWeeds or CropAndWeed draws a box around each plant. It needs Python and a GPU to train, so it's a good stretch goal for the team's research.

    Recommended

    Google Teachable Machine (TensorFlow.js)

    Free, no code, trains in the browser, and runs inside this page. Each scan zone is cut out and sent to the model, which answers Crop, Partial weed or Weed.

    1. Take 100+ close-up photos for each class: Crop, Partial weed, Weed (add Soil too if you like).
    2. Make an Image Project at teachablemachine.withgoogle.com and train it.
    3. Export → TensorFlow.js → Download. You get model.json, weights.bin and metadata.json.
    4. Load all three files here, then pick the model in the engine menu.
